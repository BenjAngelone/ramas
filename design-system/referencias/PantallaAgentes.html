// Agentes

Conectar agentes

Los agentes leen nodos, escriben en la bitácora y mueven estados como cualquiera del equipo.

01Variables de entorno en la máquina donde corre claude
bash
export RAMAS_URL="https://ramas.tu-equipo.dev"
export RAMAS_TEAM_KEY="TUR-7F3K-29QA"
export RAMAS_AGENT="claude"
02Configuración MCP (.mcp.json)
json
{
  "mcpServers": {
    "ramas": { "command": "npx", "args": ["ramas-mcp"] }
  }
}
03Instrucción para el agente (pegala en CLAUDE.md / AGENTS.md)
markdown
# Ramas
Antes de empezar, leé el nodo con ramas.get("R-42").
Al terminar dejá un Resumen; si dudás, una Pregunta abierta;
por cada commit, una entrada Commit con el hash.
Valores de ejemplo: reemplazalos por los de tu instalación.
