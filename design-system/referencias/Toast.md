# Toast

`.rm-toast` abajo a la derecha, vidrio denso, con barra de tiempo inferior (5 s). Variantes: default (info), `--success`, `--warn`, `--error`, `--agent` (cuando un agente hace algo que te importa).

- Título corto en pasado o presente ("R-6 pasó a Hecho") + una línea de contexto + una acción opcional ("Ver", "Reintentar").
- Errores con `role="alert"`; el resto `role="status"`.
